To install DIMaster 2.0:

* Copy the content of the Plugins folder to the \PLUGINS folder of 3ds Max (tested with 3ds Max versions 7, 8, 9, 2008 and 2009)
* Copy the content of the Icons folder to the \UI\ICONS folder of 3ds Max, or to \UserIcons if using profiles or Windows Vista
* Copy the content of the MacroScripts folder to the \UI\MACROSCRIPTS folder of 3ds Max, or \UserMacros if using profiles or Windows Vista
* Start 3ds Max
* Select Customize>Customize User Interface...
* Locate the Category "DIMaster", drag the items (DIMline, DIMangle, DIMnote ...) to a toolbar, or to a menu/QuadMenu or assign to keys
* Save the Customized GUI
* Click any of the icons and click in the viewport to start creating...

A Help File in CHM format is provided in the \Help folder. 
It describes the basic usage of the included tools and provides some useful examples and workflow suggestions.

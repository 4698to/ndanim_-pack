# NDanim_Pack

天晴动作工具组（NDToolsBox / 天晴盒子）的开源资源包。

包含插件程序集、工具列表、脚本资源，以及安装下载客户端相关文件。新增资源请直接推送到本仓库。

## 内容概览

| 目录 | 说明 |
|------|------|
| `NDBox` | 各 Max 版本的 `NDToolsBox.dll` 等程序集（2015–2024） |
| `NDToolsBoxList` | 工具列表与资源（`ToolLists`、`Resources`） |
| `NDToolsDownload` | 安装/下载客户端程序与依赖 |
| `NDAnim_Tools` | 动画相关脚本、插件与启动项 |
| `SmartRefs 1.04.02` | SmartRefs（约 Max 2014–2017） |
| `SmartRefs 1.09.02` | SmartRefs（约 Max 2018–2025） |
| `BsKeyTools` | 关键帧等工具资源 |
| `phy2skin2015` | Physique / Skin 互转相关 |
| `DIMaster_20080824` | DIMaster 2.0（较旧 Max 版本） |

## 支持的 3ds Max 版本

- 主插件（`NDBox`）：**2015–2024**
- SmartRefs：约 **2014–2025**（分两个版本目录）
- 部分历史工具（如 DIMaster）面向更早版本，见各目录内说明

具体工具是否可用，以对应目录及工具列表配置为准。

## 安装路径

通过安装器部署时，资源安装到：

```
C:\ProgramData\Autodesk\ApplicationPlugins\NDToolsBox\
```

也可从官网入口下载安装：

- [下载安装](https://sundaybox.cc/ndtooldata/)
